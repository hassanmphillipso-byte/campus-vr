# 校园人物 v0.2 接入资产

来源：`/Users/a1234/Desktop/code/中国高中生动漫角色组`，2026-10-07 制作检查版。

12 个角色、18 个外观版本（6 学生各有蓝黄两套，4 教师、2 保安）。本目录仅部署 GLB，未把 VRM/Blender 工程重复下载到浏览器。原工程保留全部源文件。

- `manifest.json` 是原始资产清单和哈希；本目录 GLB 文件名对应其中 `output/v02/`。
- `campus-roster-mapping.json` 是上游建议，不是本次应用清单；实际接入范围以 `js/campus_cast.js` 和 `js/classrooms/actors.js` 为准。
- `licenses/` 与 `asset-sources.csv` 保留来源和许可差异证据。基础为 VRoid/pixiv + hinzka，不是 CC0。原始嵌入元数据与作者后续公开许可不同，不删除来源文件。
- 这是 AI 辅助制作的可动检查版。成人年龄感、肩袖接缝、服装与头发精修未完成；没有低面数 LOD、足底 IK、坐姿和运动专项动作，不是最终美术验收。
- 主工程保留原角色。仅为已适配的站立、步行、资料阅读、教师与保安职责使用新模型。坐姿、运动、未覆盖岗位保持原模型。
- 右上“人物外观”可切原版/新模型、蓝/黄校服；切换重载页面，课程存档不清空。近距离按需载入，最多同时 6 个精细人物、最多 2 个加载请求，远离后恢复原角色。新模型暂关闭动态投影，12 米外动画降至 15 Hz；这不是低模 LOD。

复现资产复制和 SHA256 核验：`python3 tools/sync_campus_cast.py`。默认读取上述来源目录，也可传 `--source` 指定解包目录。
