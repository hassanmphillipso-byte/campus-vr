# 独立场景模型清单与来源

本目录包含21套分别导出的原创建筑与设备模型：17间任务/配套房、2块室外篮球场、1座篮球馆、1座游泳馆。每套都有独立 `.blend`、`.glb`、碰撞/篮筐元数据 `.json`，以米为单位。

共同的桌椅与材质可以复用；建筑壳体、室内布局和用途设备在生成时按场景分别制作。完整生成脚本：`tools/build_independent_spaces.py`；支持 `-- <场景ID>` 单独重建。
